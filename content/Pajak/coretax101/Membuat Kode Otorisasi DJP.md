#### ❓Apa alasan kamu harus membuat kode otorisasi
 Jadi begini. Salah satu fitur di coretax itu kan adalah kamu bisa menandatangani dokumen elektronik. Contohnya seperti ini:
 ![[Tanda Tangan.png|540]]
 ![[Tanda Tangan Elektronik.png|543]]
 Oleh karena itu, tiap wajib pajak orang pribadi harus membuat tanda tangan elektronik. Dalam hal ini, tanda tangan elektronik bawaan di coretax berbentuk Kode Otorisasi.

#### 📋Surat2 yg bisa ditandatangani di coretax
1. Dokumen layanan administrasi, misalnya permohonan non aktif, permohonan surat keterangan fiskal dsb
2. SPT: SPT Tahunan dan SPT Masa
3. Bukti Potong Pajak
4. Faktur Pajak

#### ✍️Panduan Kode Otorisasi
Kode otorisasi memiliki ketentuan sbb:
```
a. minimal 8 digit
b. minimal 1 huruf kapital
c. minimal 1 angka
d. disertai dengan karakter khusus seperti: !,@#
```
Contoh Kode Otorisasi:
```
Pajak123!
Pajak123@
```
Password dan Kode Otorisasi DJP bisa sama. **Tapi saran saya, tolong dibedakan demi keamanan kamu!**

#### 🏃Langkah-langkah Pembuatan Kode Otorisasi
1. Klik portal saya > Permintaan Kode Otorisasi
	![[Menu Portal Saya.png]]

2. Isi sesuai gambar > Klik simpan
	![[Buat Kode Otorisasi.png]]

3. Eits Belum Selesai! Klik Portal Saya > Profil Saya > cari Nomor Identifikasi Eksternal
	![[Nomor Identifikasi Eksternal.png]]

4. Cari menu Sertifikat Digital > Klik Periksa Status > Refresh
	![[Nomor Identifikasi Eksternal - Sertifikat Digital.png]]

5. Klik Menghasilkan
	![[Nomor Identifikasi Eksternal - Menghasilkan.png]]

6. Sertel sudah valid dan bisa segera digunakan
