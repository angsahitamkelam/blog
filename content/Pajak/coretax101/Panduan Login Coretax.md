#### Hal-hal yg harus diketahui terkait login coretax 👇
- Login menggunakan NIK atau nomor KTP bagi Wajib Pajak Orang Pribadi Dalam Negeri
- Login coretax Badan menggunakan NPWP 16 digit. Apabila kamu memiliki NPWP lama, nomornya 15 digit. Kamu cukup menambahkan angka 0 di depannya.
	- Terkait dengan coretax badan usaha, kamu harus memahami [[7 Impersonating Coretax]]
- Coretax adalah aplikasi berbasis web. Jadi tidak ada install ini itu


#### Cara Login

1. Kalau kamu belum memiliki NPWP atau masih belum yakin apakah NPWP kamu masih aktif atau tidak silakan cek [[Panduan untuk daftar NPWP]]

2. Silakan menuju alamat [coretax](https://coretaxdjp.pajak.go.id/): coretaxdjp.pajak.go.id > Klik lanjutkan login
	![[coretax.png|347]]

3. Isi dengan **NIK** dan [[Panduan untuk daftar NPWP#⚠️ Password|password]]  yg sudah dibuat
	![[login coretax.png|618]]

4. Masuk di halaman login
	![[Menu Dashboard Coretax.png|618]]
