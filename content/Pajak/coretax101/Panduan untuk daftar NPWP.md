#### 😑Panduan paling realistis
##### 🏦 Panduan untuk Pendaftaran/Aktivasi NPWP Wajib Pajak Orang Pribadi
Kamu datang ke KPP terdekat, tidak masalah kamu sebagai orang Solo ~~itu~~ datang ke KPP Pratama Klaten. Bilang saja ke security kalau kamu mau mengurus NPWP.

📋 Yang perlu kamu siapkan:
- Menunjukkan KTP asli. Tidak perlu fotokopi
- Bisa login ke alamat emailmu
- Nomor kamu ada pulsanya.
- Jika kamu mendaftar NPWP, silakan bawa **kartu keluarga** terbaru.

Catatan: terkait urusan NPWP orang pribadi, hanya bisa diwakili oleh keluarga yg namanya tercantum di KK: **suami/istri, anak**
##### ⚠️ Password
Aturan pembuatan password di coretax adalah:
```
a. minimal 8 digit
b. minimal 1 huruf kapital
c. minimal 1 angka
d. disertai dengan karakter khusus seperti: !,@#
```

📌Contoh Password:
```
Pajak123!
Pajak123@
```

📋 Untuk starter kit, yg perlu kamu lakukan ketika di KPP adalah:
1. Mendaftar NPWP jika kamu belum memiliki NPWP
2. Melakukan aktivasi coretax jika kamu sudah berNPWP tapi belum bisa login coretax
3. Memastikan bahwa kamu masih bisa membuka DJP Online. Karena urusan perpajakan tahun 2024 kebawah masih menggunakan DJP Online
4. [[Membuat Kode Otorisasi DJP|Membuat Kode Otorisasi DJP]]

##### 🏦Panduan untuk Pendaftaran/Aktivasi NPWP Wajib Pajak Badan Usaha
Mirip dengan panduan Wajib Pajak Orang Pribadi. Kamu datang aja ke KPP terdekat.

Bilang saja ke security bahwa kamu ingin dipandu oleh petugas untuk mendaftarkan NPWP Badan Usaha.

📝 Yg perlu kamu bawa data2nya:
- Akte pendirian dari AHU
- Login ke alamat email yg kamu daftarkan di AHU
- Nomor HP kamu ada pulsanya

📝 Starter kit Wajib Pajak badan baru:
1. Pastikan kamu bisa login coretax menggunakan NPWP Badan Usahanya.
2. [[Membuat Kode Otorisasi DJP|Membuat Kode Otorisasi DJP]] untuk pengurus utamanya
3. memahami prinsip [[7 Impersonating Coretax|Impersonating Coretax]]
