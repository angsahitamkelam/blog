#### Hal-hal yg harus diketahui terkait keluarga 👇
- Panduan ini terkait dengan coretax kepala keluarga.
	- Untuk yg masih berkeluarga, ada di suami
	- Untuk yg sudah berpisah, ada di masing2 akun pribadi
	- Untuk yg masih berada dalam tanggungan, ada di akunnya Bapak/Ibu-nya
	- Apabila suami istri memilih untuk menjalankan kewajiban pajak terpisah, ada di masing2 akun suami istri tersebut.
- Data coretax terhubung dengan Dukcapil. Pastikan data di kartu keluarga sudah **benar dan update**.
	- Bisa jadi ada pasangan yg berpisah tapi belum mengurus data perceraiannya. Silakan urus terlebih dahulu
- isi data **DENGAN HURUF KAPITAL SEMUA** dan **SAMA PERSIS DENGAN DATA KK/DUKCAPIL**
#### Langkah-langkahnya🚶
1. Klik portal saya > Profil saya
	![[Menu Portal Saya.png]]

2. Informasi Umum > Edit
	![[Menu Informasi Umum - Edit.png]]

3. Scroll ke Informasi Umum > Pastikan semua data yg berbintang terisi > Validasi Dukcapil
	![[Pasted image 20260925145625.png]]

4. Scroll ke Unit Pajak Keluarga > Silakan tambah, atau edit/lihat/hapus
	![[Pasted image 20260925145813.png]]

5. Isian data masing2 keluarga > Pastikan benar > Klik Simpan
	![[Rincian Data Unit Keluarga.png]]
	
	Catatan:
	- Status hubungan keluarga: silakan pilih, biasanya ya anak/istri/mertua/ortu
	- Status unit perpajakan:
		- Tanggungan jika tidak ingin melaksanakan kewajiban pajak terpisah. Artinya istri bergabung dengan NPWP suami
		- Selain itu artinya memiliki NPWP sendiri
	- Status PTKP
		- TK/0 untuk anak-istri yg dalam tanggungan
	- Tanggal Mulai:
		- Diisi ketika menjadi tanggungan/memilih kewajiban pajak terpisah.
	- Tanggal Berakhir
		- Jangan diisi.
		- Kamu isi ketika memilih untuk mengakhiri status sebagai tanggungan
5. Klik simpan
	![[Pernyataan Coretax.png]]
