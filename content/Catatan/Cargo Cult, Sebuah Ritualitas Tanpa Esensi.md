Ketika Perang Dunia 2, beberapa base didirikan di pulau-pulau pelosok. Beberapa pulau itu dihuni oleh native yg masih terbelakang.

Mereka melihat para tentara memiliki perkakas canggih, makanan enak dan fasilitas yg lebih superior. Beberapa fasilitas itu dikirimkan melalui kargo udara.

Para native ini melihat tukang parkir pesawat, marshaller, bekerja dengan mengayun-ayunkan bendera. Di mata mereka, ia seperti menari-nari menyambut burung besi.

Begitu perang usai, tidak ada lagi burung besi yg mampir.

Tidak ada lagi kargo menarik.

Tetua desa dengan keterbatasannya beranggapan burung besi itu tidak datang karena tidak ada penari yg memanggil burung-burung itu.

Warga akhirnya membuat replika landasan palsu, baju warna-warni bagi para penari.

Mereka menari agar para burung besi segera berdatangan dan membawa kargo.

Mungkin kita menganggap perilaku itu hanya berlaku untuk warga native. Padahal banyak hal yg kita lakukan:

1. Mengadopsi WFH tanpa memahami esensi budaya, desain sistem, keterbatasan dan pola pikir entitas yg sukses melaksanakannya.
2. Memakai turtle neck warna hitam dan jeans biar memiliki persona Steve Jobs.
3. Bikin konten tanpa esensi
4. Klik-klik aplikasi tanpa memahami apa maksudnya
5. Menggunakan aplikasi tanpa memahami pola pikir aplikasi tersebut
